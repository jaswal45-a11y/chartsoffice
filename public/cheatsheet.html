2. Short Names Glossary Use these 1-2 word names in prompts
Short Name UI Elements Included Description & Usage
Navbar Logo, Tabs (Charts, Analytics, F&O), Dhan status, Theme toggle Top global navigation header across all pages.
Deck Category pills (All, Momentum, Breakout), Run All, Collapse toggle Screener command deck bar with scan buttons.
Left Table / Stock List Search input, 1k/2k checkboxes, count badge, table rows Left column listing stocks found by the active screener.
Watchlist Tab Watchlist dropdown, Rename, Add stock, Capacity counter Left sidebar when switched to Watchlists mode (5 x 50 stocks).
Stock Header Symbol avatar, input (RELIANCE), LTP, % Chg, 52WH, ATH, Star Top bar of the chart card with stock prices and badges.
Toolbar [D|W], [3M|6M|1Y], Checkboxes (10..RSI), Sliders, [ ‹ | › ] Single-row chart control bar above candlestick chart.
Price Pane Candlesticks, EMAs (10-200), VWAP, Pivots, Bottom Volume, AVWAP Main candlestick price and volume chart canvas.
RSI Divider Draggable horizontal splitter bar Drag up/down to adjust proportion between Price and RSI.
RSI Pane RSI (14) curve, 14-SMA line, live RSI badge Dedicated bottom RSI sub-chart pane.
Bottom Resizer Drag handle at bottom of chart card Drag up/down to adjust total chart card height.
Line Settings Modal Sliders popup for thickness, colors, line styles Opened via Sliders icon button on toolbar.
Example Instructions: "In Toolbar, make buttons smaller" • "In Left Table, change 1k filter logic" • "In Stock Header, add PE ratio".

2. Short Names Glossary Analytics Hub Sections & Modals
Short Name UI Elements Included Description & Usage
Breadth Matrix 20 SMA Dial, 50 SMA Dial, Market Regime Card, Sector filter Top 3-card institutional market breadth diagnostics overview.
20 SMA Dial Circular SVG gauge, percentage, short-term momentum label Shows % of stocks trading above their 20-day SMA.
50 SMA Dial Circular SVG gauge, percentage, intermediate trend label Shows % of stocks trading above their 50-day SMA.
Regime Card Regime badge (Healthy Bullish), A/D ratio, 52W High/Low Overall market sentiment and momentum health summary.
Sectoral Breadth Search, Sort (Change, A/D), Category pills, Donut cards grid NSE Sectoral advance/decline cards with interactive donut charts.
Indices Ribbon Horizontal scrollable ribbon of Nifty 50, Bank Nifty, Midcap Live benchmark and sectoral index quote cards with 20/50 SMA posture.
Sub-Sectors Grid 12 ranked sub-sector cards, QoQ/YoY Sales, EPS, ROCE, PE Growth & momentum tiles with instant "View Chart" hover previews.
Sector Stocks Modal Drill-down popup with Advances/Declines stock table Opens when clicking any donut chart slice in Sectoral Breadth.
Customize Modal Pin/unpin checkboxes for indices and sub-sectors Opened via "Customize Indices & Sectors" button.
Notes Window Floating sticky notes notepad synced across tabs Opened via "Notes" button on top navbar.
Example Instructions: "In Breadth Matrix, add 200 SMA dial" • "In Sectoral Breadth, sort by Advances by default" • "In Sub-Sectors Grid, show 3 columns".

2. Short Names Glossary F&O Terminal Components & Modals
Short Name UI Elements Included Description & Usage
F&O Controls Search input, Columns menu, Refresh, Dhan feed status, Export CSV Top controls toolbar directly above the filter ribbon.
Columns Menu Dropdown checklist with checkboxes to show/hide table columns Opened via "Columns ⚙" button in F&O Controls.
Custom Universe Modal for pasting custom stock symbols or picking presets Opened via "Custom Universe" button (e.g. F&O 212 list, Nifty 50).
F&O Filter Ribbon Market Cap dropdown, Sector multi-select, Build-up toggles, EMA filters Horizontal parameter bar for screening stocks and contracts.
F&O Table Master resizable data grid with live prices, OI, PCR, and indicators Main comprehensive data table in the F&O terminal.
Sticky Columns First columns (Stock Symbol, Company Name) locked during scroll Fixed left columns that stay in place during horizontal scrolling.
Column Resizers Draggable vertical dividers on table header edges Drag left/right to adjust individual column widths (double-click to reset).
Build-Up Badge Tags: Long Buildup, Short Buildup, Long Unwinding, Short Covering Visual indicator pill showing institutional futures positioning.
F&O Footer Filtered count label, pagination info, live data timestamp Bottom summary bar beneath the F&O table.
