2. How Dhan API Connection Works (Step-by-Step for Freshers) Core Mechanism

🔑 Step 1: Authentication & Credentials

Our server reads two environment variables from .env:
• DHAN_CLIENT_ID: Your unique 10-digit Dhan account number.
• DHAN_ACCESS_TOKEN: Secure 256-bit JWT access token generated in the Dhan developer portal.

⚡ Step 2: Scrip Master Security Mapping

Dhan identifies stocks by numeric IDs, not names. Our server bundles dhan_scrip_map.json (10,000+ securities) to instantly translate symbols:
"RELIANCE" ➔ SecurityID: 2885 (NSE_EQ)
"NIFTY 50" ➔ SecurityID: 13 (IDX_I)

📈 Step 3: Historical Candle Conversion

Calls POST https://api.dhan.co/v2/charts/historical. Dhan returns raw epoch array data. Our server converts it to TradingView OHLCV format:
{ time: "2026-09-04", open, high, low, close, volume }

🛡️ Step 4: Graceful Auto-Fallback Engine

If Dhan token expires, returns error, or is unconfigured, the app never crashes. It seamlessly switches to Yahoo Finance/NSE backup with zero user interruption.

2. How MongoDB Connection Works (Step-by-Step for Freshers) Connection Lifecycle

🌐 Step 1: DNS SRV Lookup Resolution

Atlas uses mongodb+srv:// URLs. Node.js resolves SRV records into 3 distributed replica-set server hostnames using configured DNS resolvers (8.8.8.8, 1.1.1.1).

🔒 Step 2: TLS/SSL Encrypted Handshake

A secure SSL socket connects to the Atlas cluster. Authentication verifies the database username, password, and IP access list (0.0.0.0/0 for cloud hosts).

🌱 Step 3: Smart Auto-Seeding & Ingest

On first connect, if Atlas collections are empty, the server automatically seeds default screeners and admin accounts directly into Atlas with zero setup needed.

🔄 Step 4: Dual-Write & Local Backup

Every time you create a screener or save a watchlist, the server writes asynchronously to MongoDB Atlas AND local JSON files, guaranteeing zero data loss.

4. Common Troubleshooting for Freshers Error Handling
Common Issue Root Cause Instant Fix
Invalid Scheme Error Accidental spaces in .env or pasting MONGODB_URI=mongodb+srv://... in value Trim URI string. Server auto-strips duplicate prefixes now.
SSL Alert Number 80 Node TLS strict certificate or DNS SRV timeout Auto-handled by dns.setServers() and dual-mode JSON fallback.
IP Not Whitelisted MongoDB Atlas Network Access blocking server IP In MongoDB Atlas ➔ Network Access ➔ Add IP 0.0.0.0/0 (Allow anywhere).
